# Go-to-market loop

Pytxo wins through **developer-led, high-density value demonstration**, not ADE-style consumer marketing alone.

```text
Open-source Rust CLI (BYOK, zero bloat) — github.com/Pytxo-dev
        ↓
Tauri UI (Reality Deck / monitoring)
        ↓
Cloud subscriptions (cache + hosted sandboxes)
```

Source of truth: [Pytxo-dev](https://github.com/Pytxo-dev) ([github-organization](/docs/github-organization)).

## Pillars

1. **Own the systems community** — Ship CLI first; solve token burn and file-lock pain for Claude Code / Aider users.
2. **Visual proof** — Live streams: side-by-side stress tests vs heavy multi-terminal UIs ([competitive-benchmarks](/docs/competitive-benchmarks)).
3. **Enterprise** — Team Space for policy, [regex-sanitization](/docs/regex-sanitization), and managed sandboxes.
