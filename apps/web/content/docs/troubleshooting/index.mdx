Start with the exact message in Work, Review, or Setup. A failed check and a failed Apply need different fixes.

## Common problems

| Problem | Next step |
|---|---|
| Codex is missing or sign-in is unknown | Finish the agent's installation or sign-in, then recheck in Setup |
| A plan cannot run | Read the blocker, fix its configuration, and build a fresh plan |
| No verification command was found | Add a test or build command that works in this project |
| Checks fail | Read the recorded command output; passing worker text is not a check result |
| Review is stale | Refresh the candidate and review the new files and checks |
| Apply was interrupted | Read the recorded recovery state before retrying |
| The installed app looks different | Check its version; this site's new Desktop workflow previews unpublished v1.2.2 |

For Desktop setup issues, see [Desktop setup](/docs/getting-started/desktop-setup). For stale, blocked, or interrupted Apply, see [Review and Apply](/docs/getting-started/review-and-apply).

## CLI and editor issues

Run `pytxo doctor` if you have the CLI installed. It checks local setup; it does not prove a task or Apply succeeded.
