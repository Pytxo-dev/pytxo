Current release: **1.2.0**.

## npm (recommended)

Requires Node.js 18+.

```bash
npm i -g pytxo@1.2.0
pytxo doctor
```

The npm package downloads the matching prebuilt binary from [Pytxo-dev/pytxo-releases](https://github.com/Pytxo-dev/pytxo-releases) on install.

## Install scripts

**Windows (PowerShell)** is a first-class path:

```powershell
irm https://raw.githubusercontent.com/Pytxo-dev/pytxo-releases/main/install.ps1 | iex
```

**macOS / Linux:**

```bash
curl -fsSL https://raw.githubusercontent.com/Pytxo-dev/pytxo-releases/main/install.sh | bash
```

Pin a release:

```bash
PYTXO_VERSION=v1.2.0 curl -fsSL https://raw.githubusercontent.com/Pytxo-dev/pytxo-releases/main/install.sh | bash
```

## Prebuilt binaries

| Platform | Asset |
|----------|--------|
| Linux x64 | `pytxo-linux-x64` |
| Linux arm64 | `pytxo-linux-arm64` |
| macOS Apple Silicon | `pytxo-darwin-arm64` |
| macOS Intel | `pytxo-darwin-x64` |
| Windows x64 | `pytxo-windows-x64.exe` |

Download from [GitHub Releases](https://github.com/Pytxo-dev/pytxo-releases/releases/tag/v1.2.0). Put the binary on your `PATH`, then run `pytxo doctor`.

**Windows-first note:** GitHub-hosted runners were account/billing-blocked for earlier v1 cuts. v1.2.0 prefers the Actions Release workflow. If the Desktop matrix is still blocked, only a fresh Windows CLI and Desktop are claimed; do not treat older macOS or Linux Desktop artifacts as 1.2.0 builds. CLI assets still target five OS/arch combinations when those jobs succeed.

Community help: [Discord](https://discord.gg/AUFRPFjSYv).

## Default TUI

Running `pytxo` with no subcommand opens the [Hypervisor Shell](/docs/getting-started/hypervisor-shell). For scripts:

```bash
pytxo run --dry-run --config pytxo.toml
PYTXO_NO_TUI=1 pytxo   # print help instead of TUI
```

## Initialize a project

```bash
pytxo trust orbit
pytxo init
pytxo doctor
```
