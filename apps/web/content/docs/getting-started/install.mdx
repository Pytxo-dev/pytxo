---
title: Install
description: Run Pytxo with npx, keep it on your PATH, or download a binary for Windows, macOS or Linux.
---

You don't need to install Pytxo to use it: `npx pytxo` runs the latest release.

## npx

```bash
npx pytxo demo
npx pytxo
```

This needs Node.js 18 or newer. The first run downloads the native binary for your platform from [Pytxo releases](https://github.com/Pytxo-dev/pytxo-releases) and checks it against the release's `SHA256SUMS.txt`; later runs start it directly.

## Keep it on your PATH

```bash
npm i -g pytxo
pytxo --version
```

`npm i -g` installs a small launcher, and the first `pytxo` command downloads the binary. npm 12 and pnpm 10 block install scripts by default, so npm prints an `install-scripts` warning about pytxo's `postinstall`. You can ignore it. Package managers that still run install scripts fetch the binary during install instead.

If the user who runs `pytxo` cannot write to the global npm folder (a root-owned prefix, or a container image), fetch the binary at install time:

```bash
npm i -g --allow-scripts=pytxo pytxo
```

### Without Node.js

**Windows (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/Pytxo-dev/pytxo-releases/main/install.ps1 | iex
```

**macOS or Linux:**

```bash
curl -fsSL https://raw.githubusercontent.com/Pytxo-dev/pytxo-releases/main/install.sh | bash
```

To pin the shell installer to one release, pass the version to `bash`:

```bash
curl -fsSL https://raw.githubusercontent.com/Pytxo-dev/pytxo-releases/main/install.sh | PYTXO_VERSION=v2.0.0 bash
```

You can also download a binary from [GitHub Releases](https://github.com/Pytxo-dev/pytxo-releases/releases), place it on your `PATH`, and run `pytxo --version`.

| Platform | CLI binary |
|---|---|
| Windows x64 (and Windows on Arm, under emulation) | `pytxo-windows-x64.exe` |
| macOS Apple Silicon | `pytxo-darwin-arm64` |
| macOS Intel | `pytxo-darwin-x64` |
| Linux x64 | `pytxo-linux-x64` |
| Linux arm64 | `pytxo-linux-arm64` |

The released binaries are the check only. The frozen 1.x commands, such as `pytxo run` and `pytxo doctor`, build from source with the default `full` feature: `cargo build -p pytxo-cli`.

## Pytxo Desktop

Pytxo Desktop for Windows x64 is frozen: no new features, and still a free download from [Download](/download). The beta installer is not code-signed yet, so Windows SmartScreen may say it does not recognize the app: choose **More info**, check that the file came from pytxo.com, then **Run anyway**. Continue with [Desktop setup](/docs/getting-started/desktop-setup).
