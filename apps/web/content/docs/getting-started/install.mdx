The current public release is **v1.2.1**. The v1.2.2 Desktop preview is not yet available as a public download.

## Windows: install Desktop

1. Open [Download](/download) and download the Windows x64 MSI.
2. Run the installer and open **Pytxo Desktop**. The beta installer is not code-signed yet, so Windows SmartScreen may say it does not recognize the app: choose **More info**, check that the file came from pytxo.com, then **Run anyway**. Updates inside the app are signed and verified before they install.
3. Install and sign in to your coding agents separately. The v1.2.2 Desktop runs Codex, Claude Code, Cursor Agent, OpenCode and Antigravity.

Desktop includes its local Pytxo core. You do **not** need to install the Pytxo CLI unless you want terminal commands, MCP, or `pytxo doctor`.

Continue with [Desktop setup](/docs/getting-started/desktop-setup). There is no current macOS or Linux Desktop installer.

## Install the CLI

For Windows, macOS, or Linux with Node.js 18 or newer:

```bash
npm i -g pytxo@1.2.1
pytxo --version
pytxo doctor
```

The npm package downloads the matching native binary. You still need your own coding agent; Pytxo does not include a model subscription.

### Without Node.js

**Windows (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/Pytxo-dev/pytxo-releases/main/install.ps1 | iex
```

**macOS or Linux:**

```bash
curl -fsSL https://raw.githubusercontent.com/Pytxo-dev/pytxo-releases/main/install.sh | bash
```

To pin the shell installer to v1.2.1, pass the version to `bash`:

```bash
curl -fsSL https://raw.githubusercontent.com/Pytxo-dev/pytxo-releases/main/install.sh | PYTXO_VERSION=v1.2.1 bash
```

You can also download a binary from [GitHub Releases](https://github.com/Pytxo-dev/pytxo-releases/releases/tag/v1.2.1), place it on your `PATH`, and run `pytxo --version`.

| Platform | CLI binary |
|---|---|
| Windows x64 | `pytxo-windows-x64.exe` |
| macOS Apple Silicon | `pytxo-darwin-arm64` |
| macOS Intel | `pytxo-darwin-x64` |
| Linux x64 | `pytxo-linux-x64` |
| Linux arm64 | `pytxo-linux-arm64` |

## Before your first run

Use a Git repository with working build or test commands. Review [folder trust](/docs/getting-started/folder-trust) before allowing execution.

The CLI can plan and run work, but there is **no `pytxo apply`**. Reviewed Apply is in Windows Desktop. On macOS and Linux, you can inspect prepared files, but cannot complete that Desktop workflow.
