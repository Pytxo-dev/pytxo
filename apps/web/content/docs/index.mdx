Pytxo splits one coding request across the agent CLIs you already use (Codex, Claude Code, Cursor Agent, OpenCode and Antigravity), runs each task in its own copy of your project, checks the combined result, and applies exactly the changes you review. Keep your editor and your existing agent accounts.

**Start here:** [Install Pytxo](/docs/getting-started/install), then [set up Desktop](/docs/getting-started/desktop-setup).

## Which version are you using?

The public download is **v1.2.3**. If your installed Desktop looks different from these guides, update it from [Download](/download).

Desktop is available for **Windows x64**. The CLI also runs on macOS and Linux, but it has no Apply command.

## Your first workflow

1. **Describe a small change.** Name the files and the result you want.
2. **Check the plan.** See which agent runs each task, the files it owns, and the test commands.
3. **Run and review.** Inspect the prepared changes and their check results.
4. **Apply when ready.** Write the reviewed changes to your repository, or discard them.

Local Core does not require a Pytxo account. Your agent's sign-in and usage costs are separate.

## What the protection covers

Reviewed Apply controls changes to **one repository**. It does not control every command, network request, or file access an agent can make. The run's enforcement receipt shows which protections were active. Passing tests mean those tests passed, not that every behavior is correct.

Learn more in [What is Pytxo?](/docs/concepts/what-is-pytxo).
