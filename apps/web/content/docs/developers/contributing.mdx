The local Rust core is **MIT-licensed**. That is a license, not a public source dump. The product repository (`Pytxo-dev/pytxo`) is **not public**. Installers and CLI binaries ship from [`Pytxo-dev/pytxo-releases`](https://github.com/Pytxo-dev/pytxo-releases).

Do not `git clone https://github.com/Pytxo-dev/pytxo.git` expecting a public checkout. If you do not already have source access, use [Install](/docs/getting-started/install) and [Download](/download).

## Development setup

These commands assume a local clone you already have:

```bash
cd pytxo
cargo build --workspace
```

Desktop from source:

```bash
cd apps/desktop
npm ci
npm run check
cd ../..
cargo build -p pytxo-desktop
```

MCP binary from source:

```bash
cargo build -p pytxo-mcp --release
```

Smoke checks:

```bash
./tooling/scripts/smoke.sh
# Windows: ./tooling/scripts/smoke.ps1
```

## Public docs

Edit MDX under `apps/web/content/docs`. Preview with `pnpm --dir apps/web dev` and open `/docs`.

## Guidelines

- Route orchestration changes through the [safety and coordination model](/docs/concepts/three-moats) where applicable
- Add tests for scheduling, worktree, and store behavior
- Update public docs when user-facing behavior changes
- Follow existing Rust formatting (`cargo fmt`) and CI

## Pull requests

Internal contributors with source access: branch from `main`, keep commits focused, ensure `cargo test` and CI pass, and link related issues or ADRs. There is no public contribution inbox on GitHub for the private source repo.
