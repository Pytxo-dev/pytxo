Pytxo is a **local agent hypervisor** for mixed headless CLIs. Vendor-native team UIs solve a related problem inside one ecosystem. Use these pages when you are choosing a coordination layer.

| Guide | Compare against |
|-------|-----------------|
| [Claude Agent Teams](/docs/compare/claude-agent-teams) | Multi-Claude sessions with shared tasks |
| [GitHub Copilot app](/docs/compare/github-copilot-app) | Copilot-native desktop supervision + worktrees |

## Short version

- Pick Claude teams when you stay Claude-only and accept experimental limits.
- Pick Copilot app when you already live in GitHub + Copilot seats.
- Pick Pytxo when you need mixed CLIs, Race Shield path claims, Signal Core scaffolding, and BYOK on your machine under one scheduler.
