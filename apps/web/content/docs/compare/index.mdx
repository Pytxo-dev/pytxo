Pytxo is a **local agent hypervisor**. It runs the coding agents you already pay for — Claude Code, Codex, Cursor CLI, and friends — under one scheduler with path collision policy, approve-to-flush sandboxes, and structural telemetry. It is not another terminal wall and not a single-vendor team UI.

Use these pages when you are choosing a coordination layer.

## When to pick Pytxo

| You want… | Pick |
|-----------|------|
| Mixed CLIs on your machine, BYOK, collision policy | **Pytxo** |
| Claude-only teammates and accept experimental limits | Claude Agent Teams |
| GitHub + Copilot seats with worktree-per-session | Copilot app |
| Agents that keep going when the laptop is closed inside Cursor’s bill | Cursor Cloud Agents |
| A visual room of agent terminals | ADE / BridgeSpace-style |
| Fleet ops for cloud agents | Warp Oz |
| A managed remote “AI engineer” seat | Devin / Amp |

## Short frame

- **Runs the agents you already pay for.**
- **Local agent hypervisor** — silicon and keys stay yours.
- **Collisions are a systems problem** — Race Shield path claims.
- **Approve to flush** — Blast Shield until you say so.
- **Structural telemetry, not terminal walls.**

Forbidden claims elsewhere on this site: “only multi-agent,” invented worktrees, fake 10×, ADE hero theater.
