This source candidate targets **1.3.4**, which is also the latest public GitHub and npm release (the public beta).

Release notes and installers live on [GitHub Releases](https://github.com/Pytxo-dev/pytxo-releases/releases). Desktop and CLI ship from that distribution repo, not from a docs-only changelog.

| Version | Notes |
|---------|--------|
| 1.3.4 | Security patch: HTTPS certificate checks in the CLI, MCP server and Desktop reject the distrusted emSign intermediates (rustls-webpki 0.103.16 and webpki-roots 1.0.10 for RUSTSEC-2026-0381, 0382 and 0383); no other changes |
| 1.3.3 | Several sign-ins per agent CLI: [`pytxo accounts`](/docs/reference/cli#pytxo-accounts) and Desktop **Setup → Agent CLIs** keep more than one Claude Code or Codex account, and new work uses the one you pick; a worker that exits 0 after printing a CLI error and changing nothing now fails instead of passing; logs redact Anthropic keys, JWTs and JSON token fields, and Windows profile paths are redacted in full |
| 1.3.2 | Desktop speed on long histories: opens in 1–2 s instead of about 10 s, Work and Review open in about a quarter of a second, and a long worker log shows its newest line at once instead of after 47 s; workspace status no longer creates or upgrades a store |
| 1.3.1 | First-use fixes: the npm package installs with pnpm 10 and `--ignore-scripts`; failed checks print their error lines; `pytxo land` suggests a check and says when a check fails on every branch; next step after blocked or stale; two agents editing a default export count as the same symbol; [first landing in 5 minutes](/docs/getting-started/first-landing) |
| 1.3.0 | **Land.** `pytxo land` checks branches from any agent tool as one combined change (same-function detection, per-branch and combined checks, shadow mode, stale-safe `--apply`); receipts for every landing and Apply; `pytxo review` and `pytxo apply` bring the full loop to macOS and Linux; Pybench (`pytxo bench`); optional account with shareable receipts and the Pybench board; GitHub Action for shadow-mode checks; FAQ answers no longer cut off on the website; evidence moved into the docs |
| 1.2.5 | New work fits small windows (no text under its sticky header or bar, plan cards stay in the panel), one page-title style across Work, History, Review and Setup, and New work at the top of the sidebar |
| 1.2.4 | Terminal-style fleet monitor with activity lines, the Apply gate in Review, a notification when a background run stops, 1–9 worker keys, and a fix for new projects that could fail to open their store |
| 1.2.3 | Split works with heavy Codex reasoning settings and no longer comes back empty from Claude Code; clearer Split errors |
| 1.2.2 | Split a job with Codex or Claude Code; one request across Codex, Claude Code, Cursor Agent, OpenCode and Antigravity, with file ownership and a live fleet board; Review line diffs with the agent behind each file; checks on the combined change, refresh and stale-safe Apply; plainer Desktop wording; terminal quick start; verified release checksums |
| 1.2.1 | Fail-closed execution, verified Apply, release integrity, and deterministic commit-boundary demo |
| 1.2.0 | Work / History / Setup, epistemic receipts, evidence-ledger website |
| 1.1.1 | Desktop 2 control plane, Windows-first installer honesty, immutable Apply receipt |
| 1.0.0 | First public cut |

If a page still says v1.0.0, the site deploy is stale — production should only ship from `main`.
