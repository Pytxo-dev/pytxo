This source candidate targets **1.2.5**. The latest public GitHub and npm release is **1.2.4**, the public beta.

Release notes and installers live on [GitHub Releases](https://github.com/Pytxo-dev/pytxo-releases/releases). Desktop and CLI ship from that distribution repo, not from a docs-only changelog.

| Version | Notes |
|---------|--------|
| 1.2.5 (unreleased candidate) | New work fits small windows (no text under its sticky header or bar, plan cards stay in the panel), one page-title style across Work, History, Review and Setup, and New work at the top of the sidebar |
| 1.2.4 | Terminal-style fleet monitor with activity lines, the Apply gate in Review, a notification when a background run stops, 1–9 worker keys, and a fix for new projects that could fail to open their store |
| 1.2.3 | Split works with heavy Codex reasoning settings and no longer comes back empty from Claude Code; clearer Split errors |
| 1.2.2 | Split a job with Codex or Claude Code; one request across Codex, Claude Code, Cursor Agent, OpenCode and Antigravity, with file ownership and a live fleet board; Review line diffs with the agent behind each file; checks on the combined change, refresh and stale-safe Apply; plainer Desktop wording; terminal quick start; verified release checksums |
| 1.2.1 | Fail-closed execution, verified Apply, release integrity, and deterministic commit-boundary demo |
| 1.2.0 | Work / History / Setup, epistemic receipts, evidence-ledger website |
| 1.1.1 | Desktop 2 control plane, Windows-first installer honesty, immutable Apply receipt |
| 1.0.0 | First public cut |
