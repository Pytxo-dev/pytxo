Desktop is the Windows interface for Pytxo. It includes the local core; installing the separate Pytxo CLI is optional.

## Three destinations

| Destination | What you do here |
|---|---|
| **Work** | Describe a task, check its plan, follow workers, and review changes |
| **History** | Find earlier runs and inspect their results and Apply status |
| **Setup** | Manage agents, workspaces, preferences, and updates |

Use the title-bar workspace switcher to choose your project. **Approvals** opens runtime permission requests. Approving one does not apply repository changes.

## Start work

Choose **New work**, enter a clear outcome, and build a plan. Confirm the files, agent, and test commands before Run. Every ready agent starts on the job; untick any you do not want, or describe the whole job and let Codex or Claude Code split it; each task runs in its own isolated copy, using Orbit and local PTY execution.

See [First mission](/docs/getting-started/first-mission) for a complete walkthrough.

## Follow a run

Select a worker to inspect its status, files, and checks. **Open output** shows its recorded console output. Switch to **List** if you prefer a row-based view of workers.

On the canvas, drag the background to pan and use the zoom controls or **Fit** to bring tasks into view. Dependency lines show recorded task relationships.

The animated character glyph is decorative. Use the written status to judge a run; movement does not prove execution or success. Reduced motion keeps the same information visible.

## Review changes

Open **Review changes** from Work or select a run in History. Inspect the exact prepared files and combined checks before Apply. If the result is stale or recovery is unresolved, follow the displayed next step.

See [Review and Apply](/docs/getting-started/review-and-apply) for what each state means.

## Understand the protection receipt

A run reports its workspace, host filesystem, network, and Apply protections:

| Status | Meaning |
|---|---|
| Enforced | A mechanism held this boundary |
| Advisory only | The boundary was requested but not guaranteed |
| Unavailable | There is no verified protection result |
| Bypassed | The protection was deliberately disabled |

Advisory or unavailable protection is not a pass.

## Voice and updates

Voice turns speech into an editable request. It does not approve or start work automatically. Review the transcript and plan before running.

Use **Setup → General** for update checks, and verify the running version after an install. See [Desktop setup](/docs/getting-started/desktop-setup) for requirements and update guidance.
