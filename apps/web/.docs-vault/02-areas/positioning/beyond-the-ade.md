# Beyond the ADE

Many **agentic development environments (ADEs)** treat multi-agent work as a **visual layout problem**: grids of terminals, avatars, and chat panes inside a heavy IDE shell.

That model optimizes for demos, not systems throughput. Competitors such as BridgeSpace-style workspaces can render many parallel terminal feeds in webviews, which increases RAM and GPU load while tying users to proprietary cloud credits.

## Pytxo’s stance

Pytxo rejects the “virtual team room” as the primary abstraction. It targets developers who already have an IDE or editor they prefer.

Pytxo is an **agent hypervisor** with structural telemetry ([[product-vision]]) — Signal Core, Blast Shield, Race Shield — not another ADE terminal wall.
