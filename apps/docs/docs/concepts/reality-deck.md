# Reality Deck

The **Reality Deck** is an optional Tauri desktop app (`apps/desktop`) for **passive telemetry** — runs, topology, and diffs — not a multi-pane terminal grid.

## Design principles

- **Obsidian void** palette (`#020205`) with teal, violet, and solar gold accents
- Structural visualization over raw terminal walls
- Roadmap: interactive 3D AST dependency topology showing blast radius of agent edits

## What it is not

- Not a replacement for your IDE
- Not the primary surface for reading agent stdout (logs are supporting panels)
