# Go-to-market loop

Pytxo wins through **developer-led, high-density value demonstration**, not ADE-style consumer marketing alone. Proof and honesty prerequisites: [[competitive-benchmarks]], [[pytxo-improvement-research]].

```text
Open-source Rust CLI (BYOK, zero bloat) — github.com/Pytxo-dev
        ↓
Tauri UI (Pytxo Desktop / monitoring)
        ↓
Cloud subscriptions (cache + hosted sandboxes) — only when dispatcher/Link are non-noop
```

Source of truth: [Pytxo-dev](https://github.com/Pytxo-dev) ([[github-organization]]).

## Pillars

1. **Own the systems community** — Ship CLI first; solve token burn and file-lock pain for Claude Code / Codex / Aider users (cross-CLI hypervisor wedge).
2. **Visual proof** — Live streams and pinned benches vs heavy multi-terminal UIs **and** vendor control-center narratives ([[competitive-benchmarks]], [[pytxo-vs-github-copilot-app]]).
3. **Enterprise** — Team Space for policy and [[regex-sanitization]]; managed sandboxes only when [[hybrid-execution]] is configured.

Do not funnel Core users into Cloud/Ultra copy that implies live meter or GA sandboxes before Link/dispatch E2E ([[tiers-hobbyist-pro-max]]).
