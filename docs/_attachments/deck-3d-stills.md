# Reality Deck 3D marketing stills

Export PNG stills from the Reality Deck **AST topology (3D)** pane for marketing and docs.

## Path convention

Store files in this directory (`docs/_attachments/`):

| File | Use |
|------|-----|
| `deck-3d-topology-light.png` | Light theme hero still |
| `deck-3d-topology-dark.png` | Dark theme hero still |
| `deck-3d-symbol-nodes.png` | Close-up showing `::` symbol nodes (smaller violet spheres) |

Reference from vault notes as `![[deck-3d-topology-dark.png]]` per [[style-guide]].

## Capture steps

1. Open Reality Deck with a run that has structural telemetry loaded.
2. Select a node to show the selection chip in the 3D header.
3. Toggle light/dark theme as needed.
4. Export at 2× resolution; keep under ~500 KB (PNG or WebP).

Do not embed `data:image` base64 in markdown.
