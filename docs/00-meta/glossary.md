# Glossary

Canonical product and engineering terms for Pytxo.

| Term | Definition |
|------|------------|
| **Agentic control plane** | Layer that spawns, schedules, secures, and meters headless coding agents |
| **ADE** | Agentic development environment—often UI-heavy multi-agent IDEs |
| **Execution yard** | Processes running agent CLIs under orchestration |
| **Reality Deck** | Desktop dashboard for live execution telemetry ([[presentation-passive-telemetry]]) |
| **Orchestration layer** | Rust core: PTY, DAG, scaffolding, WAL |
| **Presentation layer** | Svelte + Tauri UI; no direct filesystem access |
| **Pytxo Cloud** | Hosted sandboxes for offload ([[hybrid-execution]]) |
| **Pytxo Link** | P2P remote control with signing ([[pytxo-link-signing]]) |
| **BYOK** | Bring your own LLM API keys |
| **MCP hub** | Local-first Model Context Protocol router ([[mcp-hub-integration]]) |
| **Adaptive Semantic Scaffolding** | tree-sitter fidelity tiers ([[adaptive-semantic-scaffolding]]) |
| **Sovereign Shield** | Sanitization + cryptographic remote approvals |
| **Sparse overlay FS** | FUSE/ProjFS virtual workspace ([[sparse-overlay-fs]]) |
| **DAG flow engine** | Parallel task scheduler ([[dag-flow-engine]]) |
| **Token arbitrage** | Pro-tier cloud context cache ([[token-arbitrage]]) |
