# Jev Routing + Orchestration Foundation

**Goal:** implement the user's full beta-grade foundation: qualified profiles, durable bounded attempts, event-driven advisory routing, portable handoffs, safe parallel waves, benchmark history and Desktop visibility through real runtime flows.

**Architecture:** the existing DAG and reviewed Apply boundaries remain authoritative. Add shared Core contracts, transactional per-domain attempt state, exact adapter launches, frozen handoff inputs and optional advice. Integrate the existing Work/History surfaces without redesign.

**Stack:** existing Rust/Tokio, SQLite, PTY/subprocess, Svelte/Tauri.

## Global constraints

- Core alone authorizes permissions, spending, secrets, task state, verification, candidate identity and Apply.
- No paid inference calls, hosted activation or production routing during development.
- Explicit experimental config defaults off. Shadow records advice but executes deterministic policy. Live requires evaluated policy, readiness and authorization.
- Preserve subscription/API/local billing ownership; no unsupported capability claims.
- Bound attempts, resources and concurrency. Preserve reviewed DAG semantics.
- Target Orbit/Galaxy in one repository/execution domain; no Supernova/DeepSpace reviewed Apply expansion.
- Preserve unrelated dirty checkout work. One code implementer at a time with independent read-only review. No commits, resets, cleanup or deployment.
- Tests first, focused checks after each change, broader combined verification and actual runtime/UI evidence before completion.
