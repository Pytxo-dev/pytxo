# Chroma Aperture identity

Pytxo is a monochrome control plane with a live spectrum. The spectrum represents work moving through an execution boundary: planned, isolated, coordinated, reviewed, committed.

## Rules

- Void is the default field; Ink provides the dominant contrast.
- Chroma appears on progress traces, active edges, dependency lanes, focus transitions, and commit receipts.
- A primary action is Ink on Void or Void on Ink. Never fill it with the spectrum.
- Marketing may use refracted ambient color behind real product media. Desktop may not use ambient glow.
- Prefer one continuous execution trace over several disconnected rainbow rules.
- Use Satoshi for display and UI, IBM Plex Mono for operational evidence.
- Use 4px controls and 6px panels. Full pills are exceptional.
- Motion demonstrates state change. It never decorates idle chrome.

## Surface distinction

The website explains the system and may use asymmetric editorial layouts, large type, pinned chapters, and product-led imagery. Pytxo Desktop operates the system and uses compact rows, tonal nesting, precise timelines, and persistent decision context.

Both surfaces must feel related when viewed separately. They do not need identical headers, cards, or spacing.

## Reject

Rainbow buttons, gradient text, numbered feature eyebrows, purple nebula fields, floating badges, stock people, AI sparkle marks, glass-card grids, fake terminals, decorative topology, and chroma on every border.
