# Pytxo v1.2.3

A patch release for Split with agent, the v1.2.2 feature that lets Codex or
Claude Code read your project and propose one task per line, each owning its
files.

These are prepared release notes, updated October 8, 2026, not a release
announcement.

## [fixed]

- Split with OpenAI Codex no longer times out when your Codex configuration
  sets a very high default reasoning effort. Split now asks Codex for medium
  effort, which is enough to read a project and propose owned tasks. Measured
  on the demo project with a "max" default: 71 seconds instead of hitting the
  five-minute limit.
- Split with Claude Code no longer intermittently returns no tasks. Claude Code
  now runs with only its Read, Glob and Grep tools allowed, instead of plan
  mode, which could end without printing the plan. Measured on the demo project:
  six owned tasks in 83 seconds, project unchanged.
- Split errors name the agent ("OpenAI Codex", not "codex") and no longer show
  an internal "[orchestrate]" code.

## Scope

Split stays read-only by construction: each agent is limited to read tools, and
Pytxo compares the project before and after and warns if anything changed.
Everything else is unchanged from v1.2.2.

## Install

```bash
npm i -g pytxo@1.2.3
pytxo doctor
```
