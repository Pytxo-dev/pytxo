# Pytxo v1.3.1

A first-use release. We installed Pytxo from scratch and ran `pytxo land` on a
small open-source repository with branches from Claude Code and Codex, timing
every step. This release fixes what slowed that run down or made its output
easy to misread.

These are prepared release notes, updated October 15, 2026, not a release
announcement.

## [fixed]

- **Install with pnpm or `--ignore-scripts`.** pnpm 10 blocks install scripts
  by default, and `npm i --ignore-scripts` skips them, which left `pytxo`
  saying only "binary not found". The first `pytxo` command now downloads the
  binary, checks it against the release's SHA-256 list and its version, and
  runs it. Without a network it says which address failed and installs
  nothing; a checksum mismatch is refused.
- **Why a check failed.** A failed check now prints its error lines under it,
  such as `ReferenceError: toVal is not defined`, instead of only
  `FAIL exit 1`.
- **A check that fails everywhere.** When a check fails on every branch alone
  and on the combination, `pytxo land` says the check itself may be what
  fails. For Node projects whose check does not install dependencies, it
  explains that checks run in a fresh worktree and shows a check that
  installs first, such as `npm install && npm test`.
- **Two agents editing a default export.** Signal Core now names
  `export default function` (and anonymous default classes and arrow
  functions) `default`, so two branches that change it are reported as the
  same symbol. Shared files with no common symbol say "no shared symbol"
  instead of "separate symbols", which overstated what was checked.

## [added]

- **A suggested check.** Without `--check`, `pytxo land` suggests a command
  from the project files (npm, pnpm, yarn, Cargo, Go or pytest). It never runs
  it.
- **Next step.** A blocked or stale decision ends with what to do next and the
  command that shows the full check output (`pytxo receipts show <id>`). The
  Markdown summary for pull requests gets the same lines.
- **First landing in 5 minutes.** A new docs page with the exact commands and
  measured times from the first-use runs.

## Scope

CLI, npm package and docs. Desktop, Review and Apply behaviour is unchanged
from v1.3.0. The GitHub Action defaults to installing 1.3.1.

## Install

```bash
npm i -g pytxo@1.3.1
pytxo --version
```
