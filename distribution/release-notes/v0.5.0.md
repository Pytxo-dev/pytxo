# Pytxo v0.5.0

Pytxo v0.5.0 is a focused polish and honesty pass on **Pytxo Desktop**: a compact,
adjustable shell; real data everywhere a placeholder used to be; a refreshed
onboarding flow; and a fixed release pipeline so the installers on
[pytxo.com/download](https://pytxo.com/download) actually match what CI publishes.

## Highlights

### Compact, adjustable shell

- Persisted UI scale (85% / 90% / 100% / 110%) and compact/comfortable density,
  applied live through the Tauri webview zoom API with a browser/Storybook fallback
- Fixed maximize/restore clipping on Windows — a single parent-relative height
  chain replaces the previous `100vh` / `calc(100vh - 38px)` conflict
- Sidebar, app bar, and command palette split out of one oversized inline shell
  component into focused, independently styled pieces
- Standardized compact control heights, icon sizes, focus rings, and disabled
  states so buttons no longer look mismatched across screens

### Rebuilt navigation, search, and onboarding

- Real persisted sidebar collapse/expand, with a 56px collapsed rail, tooltips,
  and keyboard focus
- Command palette rebuilt as a centered native `dialog` with `Ctrl/Cmd+K`,
  Escape, keyboard result navigation, and query filtering
- The sidebar account footer now renders only truthful account state — no more
  hardcoded name or initials — routed to real auth/entitlement data
- Onboarding is versioned so every upgrading user sees the refreshed v0.5.0 flow
  (including a new Display step for scale/density) exactly once, with **Run
  onboarding again** available from Settings at any time

### Real data, honest empty states

- Operations, Workspaces, and Focus screens now derive summaries, activity, and
  isolation status from actual domains, runs, agents, and approvals instead of
  fabricated placeholder numbers
- Hypervisor and IPC failures surface as distinct `unavailable` / `empty` /
  `error` states instead of silently collapsing to empty arrays
- Stale or temporary workspace entries are hidden from the main catalog by
  default and exposed in a reviewable cleanup section, with a safe **Forget
  domain** action that refuses domains with active runs or pending approvals
- Fixed a Windows-specific catalog bug where temporary directories were
  misidentified as permanent, which had been polluting the local workspace list

### Interaction and accessibility polish

- Restrained 140–180ms transitions on clickable rows, cards, and buttons, with a
  subtle teal hover/focus highlight and a 1px press response — not neon glows
- Hover, focus-visible, selected, loading, empty, error, and disabled states
  completed across every Desktop 2 screen
- A user-controlled reduced-motion preference disables animation independently
  of the OS setting
- Tabler is now the single icon family across the shell
- Storybook accessibility checks (color contrast, ARIA roles) now gate CI

### Correct icons, correct installers

- Regenerated transparent, optically sized application icons for Windows/macOS/
  Linux, with automated checks against transparent-corner and undersized-glyph
  regressions
- Fixed the release workflows so desktop installers are published as
  `pytxo-desktop-*` (matching what the website has expected since v0.4.0) instead
  of the legacy `pytxo-reality-deck-*` prefix, and so the auto-updater's signed
  artifacts and `latest.json` manifest are actually generated when a signing key
  is configured, rather than silently skipped

## Install

```bash
npm i -g pytxo@0.5.0
pytxo doctor
```

Download Pytxo Desktop from [pytxo.com/download](https://pytxo.com/download).

## Notes

- The legacy pre-2.0 Desktop shell remains available as an opt-in local rollback
  flag; it did not receive this release's data, motion, or accessibility work.
- The 3D topology stage (`TopologyScene3D`) is legacy-shell-only in this
  release; Desktop 2's Focus screen uses a data-first structural graph view
  instead.
