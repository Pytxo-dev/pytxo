# Pytxo v1.3.2

A Desktop speed release. On a long history, Pytxo Desktop now opens in one to
two seconds instead of about ten, Work and Review open in about a quarter of a
second, and a long worker log shows its newest line at once.

These are prepared release notes, updated October 16, 2026, not a release
announcement.

## [changed]

- **Desktop opens faster.** On a test history of six projects with 400 runs
  each (about 590,000 recorded events), launch to a ready window took 9.6 s
  with the previous release and 1.0 to 2.7 s with 1.3.2 (median 2.0 s; 1.5 s
  when alternated run by run with the earlier build). Desktop no longer replays
  every recorded change at startup, reads the first view while its window is
  still opening, and no longer waits for the voice model check.
- **Screens open faster.** Work went from 528 ms to 235 ms and Review from
  575 ms to 241 ms; reloading the window went from 7.5 s to 0.4 s. Opening a
  project store no longer repeats its schema checks, read requests no longer
  queue behind each other, run lists read only the state they show, and
  screens reuse saved requests until something changes.
- **Long worker logs.** The newest line of a 5,000-line worker log used to
  appear after 47 seconds; it now appears in under 0.1 s. Output loads in
  large pages back to back instead of 200 lines every two seconds.
- **Workspace status only reads.** Listing workspace status opens each project
  store read-only. It no longer creates a missing store or upgrades an old one
  just to show a summary.

## Scope

Desktop and the store read path. Review, Apply, verification states,
permission profiles and execution domains are unchanged. CLI and npm package
behaviour is unchanged from v1.3.1. The GitHub Action defaults to installing
1.3.2.

## How we measured

`tooling/benchmarks/desktop-perf.mjs` drives the native release build on
Windows 11 against an isolated `PYTXO_HOME` seeded by
`crates/pytxo-store/examples/seed_history.rs`. Numbers are medians of five
runs (three for the previous release) on a machine that was also running
other work.

## Install

```bash
npm i -g pytxo@1.3.2
pytxo --version
```
