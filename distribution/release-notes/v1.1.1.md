# Pytxo v1.1.1

Pytxo v1.1.1 makes Desktop a quieter instrument while keeping the v1.1 review
and Apply contract unchanged.

## [changed]

- Desktop nav is **Ops, Missions, Approvals, Workspaces, Agents, Settings**.
  Focus and Runs are no longer separate destinations. Deep-link aliases
  (`#/flow`, `#/integrations`, `#/runs`, `#/topology-focus`, `#/run-review`)
  still resolve.
- **New mission** composer plus mission **Plan / Live / Review**. Review still
  applies the immutable prepared package (ADR-0033 / ADR-0034).
- Calm Chroma: teal accent, Void and Light only. Spectrum, Nebula, and
  Terminal skins are gone.
- Replaced the decorative top-bar status cluster with workspace, page name,
  and Local/Offline.
- Rewrote comparison documentation around each product's strongest fit,
  Pytxo's concrete difference, and Pytxo's limitations.
- Added a concise architecture guide explaining what v1.1 changed and the
  exact boundary of reviewed Apply.
- Aligned Rust CLI, npm CLI wrapper, Desktop package, and installer metadata
  on version 1.1.1, with a release-time parity check.

## [fixed]

- Kept the account and billing control visible at compact Desktop heights by
  separating fixed sidebar controls from the scrolling navigation region.
- Removed duplicated healthy-state ornaments and repeated workspace status
  text.
- Updated current competitor descriptions, including Warp Oz local and
  self-hosted execution and Claude Code's separate worktree modes.
- Regenerated product screenshots from the quiet-instrument Desktop surface.

## Scope

This patch does not broaden reviewed Apply. It remains limited to Orbit and
Galaxy, one execution domain, and one repository root. Pytxo applies only the
prepared package and reconciles process interruptions through its local
journal. It does not include a planner rewrite.

## Install

```bash
npm i -g pytxo@1.1.1
pytxo doctor
```

Windows CLI and Desktop artifacts:

- https://github.com/Pytxo-dev/pytxo-releases/releases/tag/v1.1.1

## Upgrade notes

- `ONBOARDING_VERSION` remains `1.1.0`, so existing Desktop users are not
  forced through the wizard again.
- Orbit still requires human approval before applying changes.
- Vendor sessions and direct API credentials remain separate.
