# Pytxo v1.1.1

Pytxo v1.1.1 makes Desktop quieter and easier to read while keeping the v1.1 review and Apply contract unchanged.

## [changed]

- Replaced the decorative top-bar status cluster with a compact Operations summary for running work, approvals, and estimated cost.
- Simplified Flow, Workspaces, Integrations, Approvals, Operations, and Appearance copy so controls describe actions and state directly.
- Rewrote comparison documentation around each product's strongest fit, Pytxo's concrete difference, and Pytxo's limitations.
- Added a concise architecture guide explaining what v1.1 changed and the exact boundary of reviewed Apply.
- Aligned Rust CLI, npm CLI wrapper, Desktop package, and installer metadata on version 1.1.1, with a release-time parity check.

## [fixed]

- Kept the account and billing control visible at compact Desktop heights by separating fixed sidebar controls from the scrolling navigation region.
- Removed duplicated healthy-state ornaments and repeated workspace status text.
- Updated current competitor descriptions, including Warp Oz local and self-hosted execution and Claude Code's separate worktree modes.
- Regenerated product screenshots from the final 1.1.1 Desktop surface.

## Scope

This patch does not broaden reviewed Apply. It remains limited to Orbit and Galaxy, one execution domain, and one repository root. Pytxo applies only the prepared package and reconciles process interruptions through its local journal.
