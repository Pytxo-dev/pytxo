# Pytxo v0.3.5

Pytxo Desktop first-run polish, quieter control-plane chrome, and Hypervisor Shell TUI restraint. Product surface is **Pytxo Desktop** (installer filenames still use the legacy `pytxo-reality-deck-*` prefix).

## What's new

### Pytxo Desktop
- **Setup wizard** — labeled progress + Back; CLI install that succeeds with session sidecar (no false PATH fail); auth waiting/timeout; workspace errors + recent folders; Orbit / Blast Shield microcopy on Done
- **Shell chrome** — Void default, Nebula demoted as vivid; quieter toolbar; Chroma accents on topology nodes
- **Trust surfaces** — permission ceiling + Plans link in toolbar when entitlements apply

### CLI / Hypervisor Shell
- Restrained TUI borders; two-line board header; Approvals strip; `Ctrl+↑/↓` scrollback with auto-follow
- Galaxy HITL on stdin and public egress; flush fails closed unless manual approve path

## Install

**Pytxo Desktop** — [pytxo.com/download](https://pytxo.com/download)

| Platform | File |
|----------|------|
| Windows x64 | `pytxo-reality-deck-windows-x64.msi` |
| macOS Apple Silicon | `pytxo-reality-deck-darwin-arm64.dmg` |
| macOS Intel | `pytxo-reality-deck-darwin-x64.dmg` |
| Linux x64 | `pytxo-reality-deck-linux-x64.AppImage` |

**CLI (recommended alongside Desktop)**

```bash
npm i -g pytxo@0.3.5
pytxo doctor
```
