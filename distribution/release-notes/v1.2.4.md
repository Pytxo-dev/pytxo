# Pytxo v1.2.4

A Desktop release that makes a multi-agent run easier to follow while it works
and easier to trust when it lands, plus a fix for opening new projects.

These are prepared release notes, updated October 9, 2026, not a release
announcement.

## [added]

- **Fleet monitor.** The top of a multi-agent run lists every task with its
  agent, the task in words, a line of its output activity over time, its state
  and how long it has run. Beside it, an ASCII scope shows one orbit per step
  and one numbered mark per task. The activity line shows how much an agent
  printed, not how far along it is; an agent silent for 45 seconds shows
  **quiet**, because Pytxo cannot tell thinking from stuck.
- **Apply gate in Review.** The top of Review shows each condition Apply waits
  on: agents finished, a prepared change with files in it, checks on the
  combined change, and your project matching the review. Each has one mark:
  ✓ recorded, ○ not known yet, ✗ failed. Apply still checks your project again
  when you choose it.
- **Notification when a run stops in the background.** One system
  notification says how many agents finished and how many failed. It reports
  what the agents said; Review shows whether the combined change passed.
- **Number keys on the fleet board.** 1–9 jump to that worker's pane; Enter
  opens its output.
- New work shows the agents you selected before you build a plan.

## [changed]

- Fleet workers, plan steps, the Canvas, History and Setup use one terminal
  style: framed panes with their title in the border, mono status text and a
  `| / - \` spinner for live work.
- Queued tasks take less space and open into a full pane when their agent
  starts; the board follows a newly started worker unless you are scrolling.
- Review's code view fills the space above the Apply decision.
- A Run that Pytxo refused now says "Run did not start" with the reason,
  instead of reporting the plan as stale.

## [fixed]

- Adding a new project could fail with "duplicate column name" or "database is
  locked" when Desktop opened its store from several places at once, and could
  leave that store unable to open. Store setup is now serialized, and stores
  left in that state are repaired the next time they open.
- The New work agent preview no longer clips at the default 1280-pixel window.

## Scope

Apply, verification and refusal rules are unchanged from v1.2.3. Desktop is
Windows x64; macOS and Linux have the CLI.

## Install

```bash
npm i -g pytxo@1.2.4
pytxo doctor
```
