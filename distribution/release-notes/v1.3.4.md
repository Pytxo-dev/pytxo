# Pytxo v1.3.4

A security patch. The CLI, the MCP server and Desktop now use the rustls
certificate checks and bundled root certificates that reject the distrusted
emSign intermediates.

These are prepared release notes, updated October 21, 2026, not a release
announcement.

## [fixed]

- **Distrusted emSign intermediates.** RustSec published three advisories on
  October 19 and 20, 2026 (CVE-2026-111943): the private keys of some emSign
  intermediate certificates are now public, and affected versions could accept
  a certificate path through them. Pytxo's HTTPS connections (Pytxo account
  sign-in, receipt sharing, the agent catalog, Desktop update checks and hosted
  routing) verify certificates with rustls, so 1.3.4 updates the crates that
  do it:
  - rustls-webpki 0.103.15 → 0.103.16 (RUSTSEC-2026-0382), which rejects paths
    containing those public keys;
  - webpki-roots 1.0.7 → 1.0.10 (RUSTSEC-2026-0381) and webpki-root-certs
    1.0.7 → 1.0.10 (RUSTSEC-2026-0383), which drop `emSign ECC Root CA - G3`
    from the bundled roots.

  webpki-roots 0.26.11 is still in the build because ureq 2.x requires it. That
  version only re-exports the root list from webpki-roots 1.0.10, so it carries
  the fix.

## Scope

Dependency versions only. No Pytxo source changed: Review, Apply, `pytxo
land`, receipts, verification states, permission profiles and execution domains
behave as in 1.3.3. The GitHub Action defaults to installing 1.3.4.

## Install

```bash
npm i -g pytxo@1.3.4
pytxo --version
```
