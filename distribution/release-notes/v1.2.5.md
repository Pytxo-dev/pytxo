# Pytxo v1.2.5

A Desktop polish release: New work fits small windows, every destination uses
the same page title, and New work moves to the top of the sidebar.

These are prepared release notes, updated October 10, 2026, not a release
announcement.

## [changed]

- **New work at the top of the sidebar.** The sidebar's first row held only
  the collapse button; New work now sits there beside it, lined up with the
  main header. With a draft open it reads "Draft".
- **One page-title style.** Work, New work, History, Review and Setup titles
  share one size and weight, scaled by the density setting.
- **Saved requests** sits in the New work heading instead of floating over the
  plan.

## [fixed]

- With compact density, text could show above New work's "Describe the job"
  header and below its Split / Build plan bar while scrolling. Both now cover
  the content behind them.
- In narrow windows, New work no longer leaves a gap under its title, keeps
  "Lead agent" on one line, wraps the agent buttons together, and keeps plan
  steps and long file paths inside the panel.
- In narrow windows, the details of a Review gate step open in place instead
  of running past the window edge.
- With the Light theme, text typed into New work's request box was nearly
  invisible (light gray on white). It now uses the theme's text colour.
  Saved request titles and empty-state labels had the same problem; they now
  use theme colours too.

## Scope

Interface changes only. Run, verification, Review and Apply behaviour is
unchanged from v1.2.4. Desktop is Windows x64; macOS and Linux have the CLI.

## Install

```bash
npm i -g pytxo@1.2.5
pytxo doctor
```
