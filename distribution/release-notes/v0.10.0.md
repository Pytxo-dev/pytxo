# Pytxo v0.10.0

Windows auth deep-link fix, Flow as a dedicated Tauri window, Ops habit loops, and expanded compare docs.

## Highlights

- **Sign-in fix** — Windows second-instance `pytxo-deck://auth` argv reaches Desktop; signed-in state updates
- **Flow window** — real Tauri second window (`#/flow-standalone`), chrome-free mission planning
- **Flow UX** — Write → Build → Review → Run; Workspace / Agent CLI labels; empty states with CTAs
- **Ops** — Running / Needs you / Cost strip; Race path-lock visibility; shorter sidebar labels
- **Compare docs** — Cursor Cloud, ADE, Warp Oz, Devin/Amp + refreshed Claude / Copilot pages

## Install

```bash
npm i -g pytxo@0.10.0
```
