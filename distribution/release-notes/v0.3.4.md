# Pytxo v0.3.4

Production go-live: Ultra inference proxy, DeepSeek-first billing, Railway production stack, and Reality Deck updates.

## What's new

### Ultra and billing
- **DeepSeek default** — Ultra routes via `https://proxy.pytxo.com/deepseek` (`deepseek-chat`)
- **ADR-0024** — `billing.inference_proxy_url` split from Link; doctor checks proxy + cloud health
- **Link wallet** — `GET /v1/wallet/balance` for Ultra metering
- **Proxy** — streaming metering, rate limits, `providers_configured` health signal

### Production stack
- **Railway** — `link.pytxo.com`, `cloud.pytxo.com`, `proxy.pytxo.com`
- **Enterprise GA** — org seats, policy admin API, audit trail
- **Cloud hardening** — non-root Docker, optional Redis cache, egress allowlist

### Reality Deck
- CSP allows Link, proxy, and Cloud endpoints
- Symbol-level 3D topology nodes

## Install

**CLI (recommended)**

```bash
npm i -g pytxo@0.3.4
pytxo doctor
```

**Direct download** — [pytxo-releases v0.3.4](https://github.com/Pytxo-dev/pytxo-releases/releases/tag/v0.3.4)

```bash
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/Pytxo-dev/pytxo-releases/main/install.sh | bash

# Windows (PowerShell)
irm https://raw.githubusercontent.com/Pytxo-dev/pytxo-releases/main/install.ps1 | iex
```

**Reality Deck (desktop)** — [pytxo.com/download](https://pytxo.com/download)

## Verify
